# Guardians of the Rift

**Guardians of the Rift** is a top-down roguelike action game where a group of heroes battle through corrupted realms, defeat powerful bosses, and close unstable rifts threatening the world. Players collect loot, upgrade gear, unlock abilities, and evolve their build each run to survive increasingly dangerous encounters.

---

## Gameplay Overview

In *Guardians of the Rift*, players are dropped into hostile, procedurally structured rooms filled with enemies, traps, and bosses. Each run challenges players to adapt, survive, and grow stronger through loot and upgrades.

Core gameplay loop:
- Enter a rift and explore interconnected rooms  
- Fight waves of enemies using fast-paced top-down combat  
- Defeat bosses guarding progression and rift closures  
- Collect loot including gear, items, and upgrades  
- Strengthen your character between encounters and runs  
- Push deeper into the rift as difficulty escalates  

---

## Features

- Top-down real-time combat system  
- Loot-based progression and upgrades  
- Gear, abilities, and item synergy system  
- Boss fights with unique mechanics  
- Tile-based room and level generation  
- Modular UI system including health bars and menus  
- Sprite-based animations and visual effects  
- Options and menu navigation system  

---

## Development Notes

The project is built around modular systems to support scalability and future expansion. Room-based design allows for flexible level creation, while the loot and upgrade systems are designed to support multiple playstyles and replayability.

Key systems:
- Room-based progression system for structured gameplay flow  
- Health bar and UI components built as reusable scripts  
- Tile generation system for dynamic room layouts  
- Menu system with secondary navigation support  
- Data-driven approach to items, enemies, and upgrades
